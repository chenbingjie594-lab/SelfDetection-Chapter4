Holdouts contain 46/46/46 images, class counts Flash 27/27/27 and Black 32/31/30. Training was fixed at 150 epochs, `val=False`, patience 0, and formal checkpoint `last.pt`. The independently exported formal result always uses `last.pt`; `best.pt` is retained only in local run artifacts and its distinct hash is disclosed. Thus the holdout was inspected twice computationally (automatic terminal parity pass plus formal export), but never for model selection or protocol changes. One training seed (42) was run. Existing frozen validation images were excluded.
