# Stage12 最终总结

1. Stage11 的高质量候选未进入输出，是因为同目标较低 IoU 候选获得更高分类分数，随后官方 class-aware NMS 抑制高质量候选；12/14例已逐例确认。
2. 全体174 GT中，主要瓶颈是候选生成不足（E0 82、CBCD 76），而非 NMS 或排序。
3. 分类置信度与定位 IoU 总体相关较强：Spearman约.71，source-group bootstrap CI均远离0；局部错序仍存在。
4. 极小组52例中约三分之二没有 IoU≥.75 候选；排序错误主要集中于 Flash，不是 Black。
5. DFL熵、方差、峰值概率和距离不对称与 IoU 的相关均弱，不能可靠预测质量。
6. NMS .9让 GT@.75 增加11/10，但重复框增加233/225，mAP50-95反而下降；只改抑制规则不能改善整体检测。
7. 因未训练质量预测器，本阶段没有新增推理误检；无NMS/宽松NMS已证明粗暴保留会增加背景与重复框。
8. 四项开发门槛未同时满足，不支持下一阶段开发质量感知检测头。优先研究候选生成、正样本分配和标注边界，并等待独立数据验证。

证据级别：TraceableNMS一致性、计数与指标为已证实事实；“正样本分配可能重要”是待验证假设；现有 OOF 已参与多轮设计，所有结论均为探索性而非独立泛化证据。
