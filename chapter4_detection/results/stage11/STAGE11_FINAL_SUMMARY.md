# Stage11 总结

## 结论

- 已证实：DFL 是连续期望回归，不存在“stride8 只能按 8 像素定位”的直接量化限制。
- 已证实：E0 有 12/174 个目标存在 IoU>=.75 的 NMS 前候选但最终框低于 .75，候选排序/后处理解释部分失败。
- 实验支持：宽高相对误差约 12%--14%，小框 IoU 对边界扰动敏感；但中心和尺度谁占主导尚不能由当前汇总唯一判定。
- 已证实：DFL 熵与 IoU 相关很弱，不能稳定解释高 IoU 失败。
- 实验支持：P2 峰值更接近 GT，但缺陷/正常背景特异性低于 P3，既有几何价值也有纹理风险。
- 已证实：PCRF OOF mAP50-95 仅 +0.0056、AP75 -0.0299，bootstrap 均跨零，三折趋势不一致。

## 决策

PCRF 未达到 AP75 与 mAP50-95 三折积极趋势的预设门槛，停止多随机种子训练。当前没有足够证据把第四章核心创新定为 P2 回归融合。下一步优先完成专家标注复核，并在独立来源数据上预注册验证；如继续机制研究，应先分离候选排序、中心和尺度误差，而不是继续堆叠 P2 变体。

所有指标均来自真实数据与 source-group OOF；没有使用生成图像，也没有覆盖历史结果。
