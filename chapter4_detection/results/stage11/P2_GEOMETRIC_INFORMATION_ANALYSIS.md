# P2 几何信息分析

使用 Stage10 E0 OOF checkpoint，对 138 张训练图像的 174 个 GT 各分析一次。比较 Backbone P2 与 Neck P3 的缺陷边界、外环和同图亮度匹配正常背景 ROI；原始 Detect 的 P3 分类与回归输入最大差值为 0。

| 层 | 边缘/匹配背景中位数 | >1 比例 | 峰值到 GT 中心均值(px) | 边界/外环 |
|---|---:|---:|---:|---:|
| P2 | 2.247 | 0.994 | 3.415 | 1.177 |
| P3 | 3.793 | 0.989 | 5.183 | 1.155 |

P2 的峰值平均比 P3 更接近 GT 中心，且 68.6% 实例中 P2 更近，平均优势 1.74 px，支持其保留额外空间位置信息。另一方面 P2 的缺陷/匹配背景特异性明显低于 P3，表明它也更容易传入正常纹理。P2 峰值偏差与 IoU 的 Spearman 为 -0.199，P3 为 -0.026；相关性有限，不能证明因果。

因此只把 P2 残差信息小幅注入 P3 回归分支是一个受限、可证伪的候选；不支持增加 P2 检测头或改动分类分支。汇总图为 `p2_p3_edge_specificity.png`，逐实例数据为 `p2_p3_geometry.csv`。
