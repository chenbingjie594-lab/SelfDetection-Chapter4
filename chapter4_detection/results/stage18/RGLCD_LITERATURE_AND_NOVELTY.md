# Literature and novelty boundary

Local center/surround contrast, ring or layered background estimation, variance weighting and contrast-aware gating are established ideas, especially in infrared small-target detection. Relevant primary papers include the [2024 weighted improved double local contrast measure](https://www.mdpi.com/2072-4292/16/21/4030), which already uses a variance-based weighting coefficient; the [2024 variance-difference weighted three-layer measure](https://doi.org/10.1016/j.infrared.2024.105315), which uses layered local contrast and variance difference to suppress edges; and [weighted local difference variance](https://pmc.ncbi.nlm.nih.gov/articles/PMC10006989/). The named 2025 entropy-variation work was found only through incomplete secondary indexing in this environment, so no detailed novelty claim is based on it.

RGLCD differs operationally from classical image-domain saliency/threshold methods by applying fixed ring statistics to learned P3 channels inside a YOLO classification path. It differs from repository NBR-DE's learned normal-reference/similarity route and CBCD's learned smoothing/residual gate by using an explicit valid-pixel ring mean, variance standardization and fixed exponential reliability. These are verifiable implementation differences, not proof of research originality. “Ring contrast,” “variance reliability,” exponential gating, and classification-only enhancement must not individually be claimed as novel. A broader formal literature review would be required before thesis novelty language.
