# MBRD literature positioning

MBRD does not claim that prototypes, nearest-neighbour retrieval, feature differencing, or residual fusion are individually new. [PatchCore (CVPR 2022)](https://openaccess.thecvf.com/content/CVPR2022/html/Roth_Towards_Total_Recall_in_Industrial_Anomaly_Detection_CVPR_2022_paper.html) retrieves nominal patch features from a representative memory bank for one-class anomaly scoring. [PaDiM](https://arxiv.org/abs/2011.08785) models location-conditioned normal patch-feature distributions for anomaly detection and localization. Classical [reference-template discrepancy methods](https://www.mathc.rwth-aachen.de/~bouchot/files/pubs/QCAV2011_Template_Matching_Textures.pdf) similarly compare a test texture with defect-free references. Contrastive industrial-defect methods learn discriminative representations, whereas this frozen first experiment adds no contrastive loss.

The narrow MBRD hypothesis is different: fold-specific conservative background prototypes are retrieved inside a supervised YOLO detector, and the matched reference modifies only the P3 classification input while the regression tower and P4/P5 remain frozen. M1 controls for adapter capacity and M2 controls for a non-matched background reference. Therefore only a repeatable M3 advantage over both controls could support a mechanism-specific claim.

CBCD uses a learned local smoothing residual from the current feature map; RGLCD uses fixed ring statistics and reliability gating. Neither retrieves a training-fold texture prototype matched to the current query. This architectural distinction alone is not evidence of novelty or usefulness. Prototype contamination, fold leakage, frozen-feature drift, and dominance by a small number of source images remain material risks and are audited explicitly.
