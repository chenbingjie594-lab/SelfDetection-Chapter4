# Anchor 几何覆盖分析

按真实 4096×1024 → 1536×384 + 上下 padding 的 letterbox 坐标计算严格内部 anchor。分别报告原始 GT 与当前 TAL 的16px边长下限，不能把二者混为一谈。

| 覆盖定义 | P3均值/零覆盖 | P4均值/零覆盖 | P5均值/零覆盖 | 全尺度均值/零覆盖 | 全尺度≤1 |
|---|---:|---:|---:|---:|---:|
| 原始GT | 1.70 / 3 | .37 / 111 | .10 / 156 | 2.17 / 2 | 72 |
| TAL有效框 | 4.00 / 0 | 1.00 / 1 | .29 / 123 | 5.29 / 0 | 0 |

52个输入任一边<8px的 GT，原始框全尺度均值仅1.17，2个完全零覆盖、42个≤1；TAL扩展后均值5.25且无零覆盖。Black 的原始全尺度均值1.70，低于 Flash 2.70。source-group bootstrap：原始零覆盖比例95% CI [0,.0291]、≤1比例 [.339,.489]；TAL有效框两者均恒为0。

因此原始空间采样确实稀疏，但当前 TAL 已用16px floor 主动扩大候选池。单纯增大top-k不能再增加候选，因为每个 GT 通常只有约4个P3+1个P4候选，top-k已经是10。逐实例数据与图见 `anchor_coverage_instances.csv`、`anchor_coverage_distribution.png`。
