# SFDFM Ablation Results

The preregistered gate required stable positive three-seed evidence. It failed: paired mAP50-95 changes were -0.0138, -0.0063, +0.0179; the mean was -0.0007; the source-group bootstrap interval crossed zero; and AP75 decreased in all seeds.

Therefore A1/A2 were intentionally not run. Post-hoc variant search after a negative primary result would conflict with the frozen protocol and risk validation overfitting.
