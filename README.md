# 第四章：缺陷检测实验

本仓库用于集中管理论文第四章涉及的实验代码、配置、训练日志、评估结果、可视化图表和模型权重。

## 当前实验

### YOLO11s，输入尺寸 1280

- 数据集：`PlasticBomo_detect2`
- 任务：目标检测
- 类别：`Flash point`、`Big black spots`
- 正式实验：`logs/baseline_1280_20261003_075057/`
- 冒烟实验：`logs/smoke_1280_20261003_073323/`
- 正式实验最佳权重：`logs/baseline_1280_20261003_075057/weights/best.pt`

正式实验最佳模型在验证集上的总体指标：

| Precision | Recall | mAP50 | mAP50-95 |
| ---: | ---: | ---: | ---: |
| 0.732 | 0.719 | 0.791 | 0.266 |

验证集包含 102 张图像、26 个目标。当前目录尚未包含训练入口脚本；后续实验代码应与对应配置和结果一并提交。

## 目录约定

- `logs/`：每次训练的日志、配置、曲线、预测示例和权重
- `weights/`：基础模型或公共预训练权重
- 后续建议将训练代码放入 `src/`，实验配置放入 `configs/`，论文用表格和图片放入 `paper/`

## 实验记录要求

每次实验应至少记录模型、数据集版本、随机种子、输入尺寸、超参数、运行环境、最佳轮次及验证/测试指标。实验目录名应保持唯一，避免覆盖已有结果。
